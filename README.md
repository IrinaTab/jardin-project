# Jardin — Премиальное постижерное ателье

Элегантный, многофункциональный сайт услуг пастижора: изготовление и продажа изделий из натуральных волос высшего качества (парики, накладки, трессы, челки, пряди).

## Стек технологий
- **React 18** (Functional Components, Hooks)
- **TypeScript** (строгая типизация)
- **Vite**
- **Vanilla CSS** (модульные стили компонентов, дизайн-система CSS переменных)
- **i18n** (Русский, Английский, Испанский)

## Архитектура
- Модульная компонентная структура со строгим реэкспортом через `index.ts`.
- Калькулятор индивидуального пошива с динамическим расчетом стоимости в зависимости от формы, длины и оттенка волос.
- Корзина покупок с сохранением в `localStorage`.
- Мультиязычность с переключением на лету.
- Адаптивный дизайн (Mobile-first) в эстетике тихого люкса (Deep Black & Gold).

## Запуск проекта
```bash
npm install
npm run dev
```

Для сборки проекта:
```bash
npm run build
```
