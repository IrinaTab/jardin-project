# Jardin — Премиальное постижерное ателье

Элегантный, многофункциональный сайт услуг пастижора: изготовление и продажа изделий из натуральных волос высшего качества (парики, накладки, трессы, челки, пряди).

## Стек технологий
- **React 18** (Functional Components, Hooks)
- **TypeScript** (строгая типизация)
- **Vite**
- **Vanilla CSS** (модульные стили компонентов, дизайн-система CSS переменных)
- **i18n** (Русский, Английский, Испанский)

## Архитектура
- Модульная компонентная структура со строгим реэкспортом через `index.ts`.
- Калькулятор индивидуального пошива с динамическим расчетом стоимости в зависимости от формы, длины и оттенка волос.
- Корзина покупок с сохранением в `localStorage`.
- Мультиязычность с переключением на лету.
- Адаптивный дизайн (Mobile-first) в эстетике тихого люкса (Deep Black & Gold).

## Запуск проекта
```bash
npm install
npm run dev
```

Для сборки проекта:
```bash
npm run build
```
## 📸 Как добавить новое фото в галерею

### 1. Подготовить фото

- Формат: JPG/PNG (WebP генерируется автоматически)
- Размер: до 800×1200 px, вес до 500 КБ
- **Имя файла:** `work-N.jpg`, где N — следующий свободный номер
  - Пример: если в папке 11 фото, новое — `work-12.jpg`

Положите файл в `public/images/works/`.

### 2. Добавить запись в `src/data/gallery.ts`

Откройте `src/data/gallery.ts` и добавьте **один объект** в конец массива:

```ts
{
  id: 'work-12',
  imageUrl: '/images/works/work-12.webp',
  title: {
    ru: 'Заголовок на русском',
    en: 'Title in English',
    es: 'Título en español',
  },
  category: 'wigs',  // wigs | toppers | wefts | custom
  description: {
    ru: 'Описание на русском',
    en: 'Description in English',
    es: 'Descripción en español',
  },
},
